Добавлено более 30 готовых к использованию шаблонов масок, организованных по категориям:

## Новые Функции

### 1. Drag and Drop (Перетаскивание файлов) ✨
- **Описание**: Полная поддержка перетаскивания файлов и папок
- **Особенности**:
  - Работает на всех вкладках с файлами
  - Поддержка папок (автоматически добавляет все поддерживаемые файлы)
  - Визуальная индикация при перетаскивании
  - Поддержка URL в соответствующей вкладке
  - Используется библиотека `tkinterdnd2` (опциональная)
- **Как использовать**: Просто перетащите файлы/папки в списки

### 2. Горячие Клавиши (Keyboard Shortcuts) ⌨️
- `Ctrl+O` - Добавить файлы/URL на текущей вкладке
- `Ctrl+S` - Сохранить результаты (на доступных вкладках)
- `Delete` - Удалить выбранные элементы из списка
- `Ctrl+A` - Выбрать все элементы в текущем списке
- `F5` - Обработать/Выполнить действие на текущей вкладке
- `Ctrl+Q` - Выход из приложения

### 3. Контекстное Меню (Правый Клик) 🖱️
- **Добавить файлы** - Открыть файловый браузер
- **Удалить выбранные** - Удалить выбранные элементы
- **Очистить все** - Удалить все элементы из списка
- **Выбрать все** - Выбрать все элементы
- **Открыть расположение файла** - Открыть папку с файлом (только для файлов)
- Работает на всех listbox'ах

### 4. Статус-Бар 📊
- Отображает текущее состояние приложения
- Показывает количество файлов/URL на текущей вкладке
- Обновляется в реальном времени
- Информативные сообщения о действиях

### 5. Валидация URL 🔒
- Автоматическая проверка URL перед добавлением
- Предотвращение добавления некорректных URL
- Информативные сообщения об ошибках
- Проверка дубликатов

### 6. Улучшенный Интерфейс 🎨
- Увеличено окно приложения (900x700)
- Обновлены заголовки вкладок с указанием Drag & Drop
- Более информативные сообщения
- Лучшая организация кода

## Структура Кода

### Новые Методы:

#### Drag & Drop
- `enable_drag_and_drop(listbox, listbox_type)` - Включение drag & drop для listbox
- `_on_drop(event, listbox, listbox_type)` - Обработчик события drop

#### Горячие Клавиши
- `setup_keyboard_shortcuts()` - Настройка горячих клавиш
- `add_files_shortcut()` - Добавление файлов через Ctrl+O
- `save_shortcut()` - Сохранение через Ctrl+S
- `delete_selected_items()` - Удаление через Delete
- `select_all_items()` - Выбор всех через Ctrl+A
- `process_shortcut()` - Обработка через F5

#### Контекстное Меню
- `add_context_menu(listbox, listbox_type)` - Добавление контекстного меню
- `add_files_for_listbox(listbox)` - Добавление файлов для конкретного listbox
- `remove_selected_from_listbox(listbox)` - Удаление выбранных элементов
- `open_file_location(listbox)` - Открытие расположения файла

#### Статус-Бар
- `setup_status_bar()` - Создание статус-бара
- `update_status_bar(message)` - Обновление статус-бара

#### Валидация
- `validate_url(url)` - Проверка корректности URL
