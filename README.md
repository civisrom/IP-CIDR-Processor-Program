# IP CIDR Processor

GUI-программа для извлечения IP-адресов из текста, преобразования их в CIDR и подготовки списков для прокси, firewall, роутеров и других систем.

## Что умеет

- Извлекает IPv4, IPv6, CIDR и диапазоны IP из обычного или "мусорного" текста.
- Корректно обрабатывает URL с IP и портом, например `http://192.168.1.1:8080`.
- Отбрасывает невалидные адреса и не считает IP внутри диапазона дважды.
- Преобразует одиночные IP в CIDR: IPv4 в `/32`, IPv6 в `/128`.
- Конвертирует диапазоны IP в минимальный набор CIDR.
- Оптимизирует CIDR-списки без расширения покрытия адресов.
- Поддерживает обычный и aggressive режим оптимизации.
- Работает с IPv4 и IPv6 вместе или по отдельности.
- Форматирует результат через маски: plain list, Clash, Surge, Quantumult X, iptables, UFW, MikroTik, JSON, CSV и другие.
- Обрабатывает локальные файлы, URL-списки и большие наборы файлов в batch-режиме.
- Поддерживает drag-and-drop файлов, папок и URL.

## Установка

Требуется Python 3.7+.

```bash
pip install -r requirements.txt
```

`tkinterdnd2` нужен для drag-and-drop. Без него программа запускается, но файлы нужно добавлять кнопкой.

## Запуск

```bash
python3 src/ip_cidr_processor.py
```

Если в системе команда `python3` недоступна:

```bash
python src/ip_cidr_processor.py
```

## Основные режимы

- **Process Files** - извлечение IP/CIDR из файлов и сохранение результата.
- **IP Ranges** - конвертация диапазона IP в CIDR и CIDR обратно в диапазон.
- **Optimize CIDR** - удаление дублей, объединение соседних сетей, сортировка результата.
- **URL Processing** - загрузка списков по HTTP/HTTPS и обработка найденных IP.
- **Batch Processing** - обработка многих файлов с прогрессом и возможностью остановки.
- **Mask Settings** - выбор, создание, копирование и настройка масок вывода.
- **Configuration** - импорт, экспорт и сброс настроек.

## Drag-and-drop

Поддерживается перетаскивание:

- файлов `.txt`, `.log`, `.dat`, `.csv`;
- папок, из которых автоматически добавляются поддерживаемые файлы;
- HTTP/HTTPS URL во вкладку URL Processing.

Невалидные URL и неподдерживаемые файлы игнорируются.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl+O` | Добавить файлы или URL |
| `Ctrl+S` | Сохранить результат, где доступно |
| `Delete` | Удалить выбранные элементы |
| `Ctrl+A` | Выбрать все в текущем списке |
| `F5` | Запустить действие текущей вкладки |
| `Ctrl+Q` | Выйти |

## Настройки

При первом запуске создается `ip_cidr_config.yaml`. В нем хранятся маски, выбранная маска по умолчанию и пользовательские настройки.

Подробное описание всех шаблонов масок находится в [MASK_TEMPLATES.md](MASK_TEMPLATES.md).

## Сборка exe

```bash
pyinstaller ip_cidr_processor.spec
```

Готовый файл будет создан в папке `dist/`.
